# Fog Carport | Semesterprojekt

## School Project by Andreas & Jonas.

Fully implemented Carport Calculator App made for Fog / XL-Byg. Calculates an estimated price for a Carport, and allows the
user to receive an offer based on input. Generates a .pdf with an .svg of their rendering. 

## Features

We've implemented the following

- Sales Menu
- Offer Page
- Calculator / Algorithm
- Status checks
- Fully implemented mail setup
- Input & Selection tools
- Frontpage with relevant information

## How to run it

Clone or Fork the Project

- Open the Project in IntelliJ and navigate to Database.java.
- Insert your PgAdmin (Postgres) information.
- Add fog and fog_test databases and insert our setup.sql file in both of the databases.
- Add our dummy.sql file into the fog database and you're ready to go.
